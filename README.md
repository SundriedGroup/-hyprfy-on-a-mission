# On a Mission — Production UI V2

Simplified production interface built on the existing Adaptive Producer + Intelligence + Stats foundation.

## Changes
- PLAN board prioritises Posting Plan + Capture Ask.
- TODAY view shows Production Plan and Posting Plan together.
- Right-hand production rail surfaces Capture Ask, Script, Post Copy and Stories.
- New POSTED view provides content history with planned / captured / edited / published filters.
- Existing Supabase production status remains the source for publishing state.
- Intelligence, Stats, Adaptive Check-in, Calendar, Moments and Monthly views remain intact.
